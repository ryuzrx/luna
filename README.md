# Luna

A study room under the moon, with an anime tutor in it. Free, no account, nothing to set up.

- **Open it:** <https://ryuzrx.github.io/luna/app/>
- **Mac app:** <https://ryuzrx.github.io/luna/downloads/Luna-mac.zip>
- **iPad / iPhone:** open the link in Safari, then Share → Add to Home Screen.

Luna has no server. Your name, conversations and any API keys stay in your own browser and are sent only to the AI provider you choose.

Character names and artwork belong to their rights holders. Tutors are fan-made study companions inspired by those characters. If you are a rights holder and want something removed, open an issue.
